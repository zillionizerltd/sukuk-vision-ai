# Agrofeed Sukuk Hub

Build an enterprise-grade, AI-powered Sukuk Data Room and collaboration platform for Agrofeed Global.

The production URL must be:

https://agrofeedglobal.com/dataroom

The platform name is:

Agrofeed Global Sukuk Data Room

The platform subtitle is:

Secure Collaboration, Sukuk Structuring and Compliance Intelligence

The platform will be used by Agrofeed Global, Tesserant, and Al Huda CIBE to upload, review, approve, analyse, and manage all documents, reports, financial information, milestones, risks, approvals, and compliance requirements related to the Agrofeed Sukuk programme.

This must not be a basic document storage platform. It must function as an intelligent Virtual Data Room, project management system, Sukuk structuring assistant, compliance monitoring system, due diligence workspace, and stakeholder collaboration portal.

The system must continuously update its analysis whenever a new document, report, milestone, financial model, approval, or project update is uploaded.

The platform must help all stakeholders:

Work from the latest and most accurate information

Track project milestones

Identify missing documents

Monitor Sukuk readiness

Review financial performance

Detect inconsistencies

Assess project risks

Recommend the most suitable Sukuk structure

Monitor Sharia, AAOIFI, IFSB, legal, regulatory, ESG, AML, KYC, and IFRS compliance

Generate reports

Assign tasks

Track approvals

Maintain a complete audit trail
